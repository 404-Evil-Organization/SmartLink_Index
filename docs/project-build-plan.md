# 智链指数项目构建方案（20天 · 4人团队）

## 一、概述

本项目采用前后端分离架构，后端 Spring Boot + MyBatis Plus，前端 Vue 3 + Element Plus + ECharts，数据库 MySQL，文件存储阿里云 OSS。**数据库设计文档和接口文档已准备就绪**，开发团队可直接基于这些文档进行编码。4人团队需在20天内完成所有核心功能开发、测试与部署。本方案采用迭代式开发，划分为5个阶段，每个阶段设定明确里程碑和交付物，确保项目按时高质量交付。

------

## 二、团队分工建议

| 角色      | 人员  | 主要职责                                       |
| :-------- | :---- | :--------------------------------------------- |
| 后端开发A | 成员1 | 核心业务模块（企业信息、诊断、协同指数）       |
| 后端开发B | 成员2 | 算法模块（匹配、信用分）、出海服务、OSS集成    |
| 前端开发A | 成员3 | 基础页面（登录、企业管理）、诊断、信用评价页面 |
| 前端开发B | 成员4 | 匹配、出海服务、可视化看板、路由/状态管理      |

**协作方式**：每日站会，每周迭代评审，使用 Git 进行版本管理（dev 分支开发，feature 分支合并），通过 Swagger/Postman 进行接口联调。

## 三、项目里程碑

### 第一阶段：环境搭建与设计文档落地（第1-3天）

| 时间 | 任务                                                         | 产出                                | 负责人      |
| :--- | :----------------------------------------------------------- | :---------------------------------- | :---------- |
| Day1 | 环境搭建：后端 Spring Boot 项目初始化，整合 MyBatis Plus、Spring Security、JWT；前端 Vite + Vue 3 项目创建，引入 Element Plus、Axios、Pinia；团队成员熟悉已有数据库设计文档和接口文档 | 项目脚手架，可运行 Hello World      | 全体        |
| Day2 | 后端：使用 MyBatis Plus Generator 根据数据库文档生成实体类、Mapper 及基础 Service；前端：根据接口文档生成 API 调用层（可手动封装或使用 swagger-codegen），并开发基础布局组件 | 后端基础代码、前端 API 层、基础布局 | 后端A+前端A |
| Day3 | 前后端联调环境配置：配置跨域、JWT 拦截器测试；编写简单测试用例验证数据库连接和接口连通性；完善项目 README 和开发环境说明 | 可联调的基础项目，环境就绪          | 后端B+前端B |

**里程碑1**：开发环境就绪，前后端基于现有文档完成基础代码生成，可进行接口联调。

## 四、风险控制与应对

| 风险                       | 可能性 | 应对措施                                                     |
| :------------------------- | :----- | :----------------------------------------------------------- |
| 算法复杂度高，匹配效果不佳 | 中     | 提前设计简单可解释的算法，先实现加权模型，后续优化相似度计算 |
| 前后端联调接口不一致       | 低     | 已有接口文档，开发过程中严格遵守，每日同步接口变更           |
| 人员请假或任务延误         | 中     | 关键任务安排两人熟悉，避免单点依赖；每日站会及时调整         |
| 部署环境问题               | 低     | 提前准备云服务器，使用 Docker 容器化保证环境一致             |
