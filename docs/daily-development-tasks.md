# 智链指数项目每日开发任务计划（20天·4人团队）

本文档基于项目构建方案（更新版），将20天的开发周期细化为每天的具体任务，明确前端和后端需要完成的工作。团队应按照此计划推进，每日站会检查进度。

**数据库构建**

先检查mysql80服务是否开启，然后去navicat或者其他数据库管理工具创建新数据库`smartlink_index`，创建好后在`cmd`里面登录本地数据库并执行以下命令

```cmd
CREATE USER 'smartlink_index'@'localhost' IDENTIFIED BY 'smartlink_index_2026';
GRANT ALL PRIVILEGES ON `smartlink_index`.* TO 'smartlink_index'@'localhost';
FLUSH PRIVILEGES;
```
