# 智链指数 (SmartLink Index)

> **面向大湾区电子信息产业中小企业的数字化转型诊断与产业协同服务平台**
> —— 评估 · 匹配 · 服务 ——

------

## 📖 项目简介

**智链指数** 是一个集 **企业数字化诊断、区域协同指数分析、智能供需匹配、信用评价体系、出海服务支持** 于一体的两业融合（制造业与服务业深度融合）智能服务平台。平台聚焦**大湾区电子信息产业中小企业**，通过数据驱动帮助中小企业“看清自己、找到伙伴、顺利出海”，同时为政府和园区提供产业协同监测工具，助力区域高质量发展。

平台采用前后端分离架构，后端基于 Spring Boot 3 + MyBatis Plus，前端使用 Vue 3 + Element Plus + ECharts，数据存储于 MySQL，非结构化文件（如资质证书）使用阿里云 OSS 对象存储。整套系统可在 20 天内由 4 人团队完成开发并部署。

------

## 🎯 项目背景与痛点

| 痛点维度           | 具体表现                                      |
| :----------------- | :-------------------------------------------- |
| **企业看不清自己** | 不了解自身数字化水平，转型方向模糊            |
| **区域看不清产业** | 政府/园区缺乏量化工具评估产业协同状况         |
| **找服务难**       | 需要检测认证、设计等服务，但找不到靠谱服务商  |
| **服务商获客难**   | 优质服务商难以触达海量中小制造企业            |
| **出海门槛高**     | 产品出口需 CE/UL 等认证，中小企业缺乏专业指导 |

------

## ✨ 核心功能

| 模块               | 功能描述                                               | 算法亮点                    |
| :----------------- | :----------------------------------------------------- | :-------------------------- |
| **企业数字化诊断** | 填写问卷快速评估数字化水平，输出雷达图与改进建议       | 加权评分模型                |
| **区域协同指数**   | 基于合作数据计算区域协同水平（合作密度、服务渗透率等） | 多维度聚合                  |
| **智能供需匹配**   | 制造企业发布需求，系统推荐最匹配的服务商               | Jaccard 相似度 + 信用分加权 |
| **信用评价体系**   | 对服务商进行资质、案例、评价多维度评分                 | 规则加权                    |
| **出海服务专区**   | 整合国际认证、物流、翻译等服务，提供国别准入指南       | 分类检索                    |
| **数据可视化看板** | 产业态势一屏掌握：热力图、协同指数排名、合作网络       | ECharts 动态展示            |

## 🚀 快速开始

### 环境要求

- Node.js 22.x LTS（推荐）
- JDK 17+
- MySQL 8.0+
- Maven 3.8+
- 阿里云 OSS 服务（可选，可使用本地存储模拟）

### 本地开发

#### 1. 克隆仓库

```bash
git clone https://github.com/404-Evil-Organization/SmartLink_Index.git
cd SmartLink_Index
```

#### 2. 后端启动

```bash
cd backend
# 复制配置文件模板，填入实际参数
cp src/main/resources/application.yml.example src/main/resources/application.yml
# 编译打包
mvn clean package
# 运行
java -jar target/zhilian-backend.jar
```

后端默认运行在 `http://localhost:8080`，API 文档访问 `http://localhost:8080/swagger-ui.html`。

#### 3. 前端启动

```bash
cd frontend
npm install
# 复制环境变量模板
cp .env.example .env
# 启动开发服务器
npm run dev
```

前端默认运行在 `http://localhost:5173`。

#### 4. 数据库初始化

执行 `backend/src/main/resources/db/schema.sql` 创建表结构，执行 `data.sql` 插入初始数据（如标签、区域枚举）。

## 📦 部署（开发中）

### 使用 GitHub Actions 自动部署

项目已配置 CI/CD 流水线（`.github/workflows/deploy.yml`），每次推送到 `dev` 或 `main` 分支会自动：

- 运行单元测试
- 构建前后端
- 通过 SCP 上传至云服务器
- 重启后端服务、更新前端静态文件

### 手动部署

1. 后端打包：`mvn clean package`
2. 前端构建：`npm run build`，生成 `dist` 目录
3. 将 `jar` 包和 `dist` 文件上传至服务器
4. 配置 Nginx 反向代理（参考 `docs/nginx.conf`）
5. 使用 `systemd` 管理后端服务（参考 `docs/zhilian-backend.service`）

详细部署手册请见 ~~[docs/deployment.md](https://docs/deployment.md)~~。
